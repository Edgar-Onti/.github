## Services

- **Business web applications and APIs**: internal platforms, dashboards and workflows with FastAPI, PostgreSQL and React.
- **ERP and SAP data integration**: reporting, pricing and document automation on top of SAP Business One and SAP HANA.
- **Machine learning in production**: models delivered as APIs and applications that people use every day.
- **Cloud deployment**: Docker, AWS and CI/CD pipelines with GitHub Actions.

## How projects run

1. **Vision**: understand the business problem and agree on a written specification before development starts.
2. **Build**: typed Python, automated tests against real databases and continuous integration on every change.
3. **Execution**: automated deployments with manual approval, plus operations documentation delivered with the system.
