- **Business web applications and APIs**: internal platforms, dashboards and workflows with FastAPI, PostgreSQL and React.

- **Machine learning in production**: models served as APIs and applications that people use every day.
- **Cloud deployment**: Docker, AWS and CI/CD pipelines with GitHub Actions.

## How I work

- Typed Python and automated tests that run against real databases.
- Automated deployments with manual approval, plus operations documentation delivered with the system.
